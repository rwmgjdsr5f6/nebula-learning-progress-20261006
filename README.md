# 课程学习进度台

计划管理课程、学习记录和完成进度。面向本地单机使用，采用 Python 3 标准库与 SQLite。

## 使用说明

通过 `python -m course_progress` 调用，每次用 `--db` 指定数据库文件（父目录需预先创建，文件不存在时自动创建）。`--db` 写在子命令前后均可。

### 登记课程

```bash
python -m course_progress --db data/course.db add-course \
    --title "Python 入门" --chapter "安装环境" --chapter "第一段程序"
```

`--chapter` 可重复，出现顺序即章节顺序。成功时标准输出：

```json
{"course_id": 1}
```

退出码 0。全新数据库的首个编号为 1，之后递增。

### 查询课程详情

```bash
python -m course_progress --db data/course.db get-course 1
```

成功时标准输出（chapters 按登记顺序排列）：

```json
{"course_id": 1, "title": "Python 入门", "chapters": ["安装环境", "第一段程序"]}
```

退出码 0。数据库文件落盘保存，退出程序后再次查询结果一致。

### 修改课程标题

```bash
python -m course_progress --db data/course.db rename-course 1 --title "Python 基础"
```

按编号修改课程标题，课程编号保持不变。新标题去除首尾空白（保留内部空白与大小写）。成功时标准输出为一行 JSON：

```json
{"course_id": 1, "title": "Python 基础"}
```

章节名称、数量与顺序均不变；改为原标题同样成功；允许与其他课程同名，但不会合并课程。

### 查询课程概览

```bash
python -m course_progress --db data/course.db list-courses
```

成功时标准输出为一行 JSON，`courses` 按课程编号升序排列，每项只含 `course_id`、`title`、`chapter_count`，不含章节名称：

```json
{"courses": [{"course_id": 1, "title": "Python 入门", "chapter_count": 2}]}
```

全新数据库尚未登记课程时自动建库建表，返回 `{"courses": []}`，退出码 0。同标题的课程分别列出。

需要按标题片段筛选时，可加可选参数 `--title-contains`：

```bash
python -m course_progress --db data/course.db list-courses --title-contains "Python"
```

筛选词先去除首尾空白（保留内部空白与大小写），再与已保存的课程标题做大小写敏感的连续子串匹配；不匹配章节名称，百分号、下划线、引号和中文均按普通字符处理，不具有通配或表达式含义。输出格式与不带参数时完全一致，只保留匹配的课程，仍按课程编号升序排列；没有匹配项时返回 `{"courses": []}`。显式传入空字符串或仅含空白的筛选词时，退出码 1，标准输出为空，标准错误输出 `课程标题筛选词不能为空`。

### 登记学员

```bash
python -m course_progress --db data/course.db add-learner --name "学员甲"
```

姓名去除首尾空白后保存（保留内部空白与大小写）。同名学员分别登记，不合并记录，也不影响课程编号；学员编号独立递增，与课程编号互不相干。成功时标准输出：

```json
{"learner_id": 1}
```

退出码 0。全新数据库的首位学员编号为 1，之后递增。

### 按编号查询学员

```bash
python -m course_progress --db data/course.db get-learner 1
```

成功时标准输出为一行 JSON，只含 `learner_id` 与 `name`：

```json
{"learner_id": 1, "name": "学员甲"}
```

退出码 0。数据库文件落盘保存，重新打开同一文件仍返回保存的姓名和编号；不同 `--db` 文件中的学员互不相见。

### 报名课程

```bash
python -m course_progress --db data/course.db enroll-learner 1 --course 1
```

为学员报名一门课程，学员编号与 `--course` 课程编号均必填。一个学员可报名多门课程，一门课程可接收多个学员；同一编号组合重复报名仍成功并返回相同内容，名册中只保留一条记录。同名学员、同标题课程按各自编号区分。成功时标准输出为一行 JSON，只含 `learner_id` 与 `course_id`：

```json
{"learner_id": 1, "course_id": 1}
```

退出码 0。仅记录报名关系，不产生学习进度或结业结果。

### 查询报名名册

```bash
python -m course_progress --db data/course.db list-course-learners 1
```

成功时标准输出为一行 JSON，`learners` 按学员编号升序排列，每项只含 `learner_id` 与 `name`，姓名使用当前保存的值（改名后显示新姓名）；课程存在但无人报名时 `learners` 为空数组：

```json
{"course_id": 1, "learners": [{"learner_id": 1, "name": "学员甲"}]}
```

退出码 0。重新打开同一数据库文件仍返回相同的报名关系。

### 失败结果

登记失败向标准错误输出中文消息，退出码 1，标准输出为空，数据库不留下任何记录：

| 情形 | 标准错误 |
| --- | --- |
| 标题去除首尾空白后为空 | `课程标题不能为空` |
| 未提供 `--chapter` 或存在空章节名 | `章节不能为空` |
| 同一课程内章节名重复（去首尾空白后按大小写敏感比较） | `章节名重复` |

多种问题同时存在时，按标题、空章节、重复章节的顺序只返回首个错误。

查询失败：

| 情形 | 标准错误 | 退出码 |
| --- | --- | --- |
| 编号不存在（正整数） | `课程不存在` | 1 |
| 编号不是正整数（如 `0`、`-3`、`abc`） | `课程编号必须为正整数` | 2 |

修改标题失败（标准输出为空，课程与章节均不变）：

| 情形 | 标准错误 | 退出码 |
| --- | --- | --- |
| 编号不是正整数（如 `0`、`-3`、`abc`） | `课程编号必须为正整数` | 2 |
| 正整数编号课程不存在（含 `9223372036854775808`） | `课程不存在` | 1 |
| 课程存在但新标题去首尾空白后为空 | `课程标题不能为空` | 1 |

多种问题同时存在时，按编号格式、课程存在性、标题非空的顺序只返回首个错误。

学员登记失败（退出码 1，标准输出为空，不留下任何记录、不占用编号）：

| 情形 | 标准错误 |
| --- | --- |
| 未提供 `--name`，或姓名去除首尾空白后为空 | `学员姓名不能为空` |

学员查询失败（标准输出为空，不显示异常堆栈）：

| 情形 | 标准错误 | 退出码 |
| --- | --- | --- |
| 编号不是正整数（如 `0`、`-3`、`abc`） | `学员编号必须为正整数` | 2 |
| 正整数编号学员不存在（含 `9223372036854775808`） | `学员不存在` | 1 |

编号带正号、前导零或外围空白时沿用课程编号的解析语义。

报名失败（标准输出为空，不修改已有数据、不新增报名）：

| 情形 | 标准错误 | 退出码 |
| --- | --- | --- |
| 学员编号不是正整数 | `学员编号必须为正整数` | 2 |
| 课程编号不是正整数 | `课程编号必须为正整数` | 2 |
| 正整数编号学员不存在（含超出 SQLite 整数范围） | `学员不存在` | 1 |
| 正整数编号课程不存在（含超出 SQLite 整数范围） | `课程不存在` | 1 |

多种问题同时存在时，按学员编号格式、课程编号格式、学员存在性、课程存在性的顺序只返回首个错误。名册查询使用相同的课程编号错误结果。

不同的 `--db` 文件中的课程与学员均彼此独立。
